## 一、事件

### 最贴合的两个

**Ronan Point（伦敦，1968）：燃气 → 结构**
住户在 18 层厨房划火柴点燃气灶，引发爆炸，吹出承重墙板，楼体一角连续坍塌，4 人死亡。调查认为它符合当时的规范，但仍不是可接受的建筑，英国后来因此修改了建筑法规。
- 对我们的价值：住宅、厨房、燃气都有，结论也很强：**合规不等于安全**。
- 资料：[事件综述](https://en.wikipedia.org/wiki/Ronan_Point) · [英国议会 1968 年辩论记录](https://api.parliament.uk/historic-hansard/commons/1968/nov/06/ronan-point-flats-report) · [Designing Buildings](https://www.designingbuildings.co.uk/wiki/Ronan_Point_gas_explosion)

**MGM Grand（拉斯维加斯，1980）：电气 → 烟 → 通风和竖井**
隐蔽空间内的接地故障引发火灾，烟经楼梯、电梯井、抗震缝和空调系统进入高层塔楼。通常说约 85 人遇难（各来源有差异），多数死于高层的烟气吸入。
- 对我们的价值：**火在楼下，死亡在楼上**，几个系统叠在一起才能看懂。
- 资料：[事件综述](https://en.wikipedia.org/wiki/MGM_Grand_fire) · [Firehouse：MGM Grand 的教训](https://www.firehouse.com/article/10465399/lessons-from-the-past-mgm-grand-fire)

### 其他案例

- **银川富洋烧烤（2023）**：不合格液化气瓶、违规操作、泄漏爆炸，31 人死亡，有国务院调查报告。阀门的具体细节要以报告原文为准。
  [人民日报](https://paper.people.com.cn/rmrbwap/html/2024-01/28/nw.D110000renmrb_20240128_1-03.htm) · [调查组答记者问](https://paper.people.com.cn/rmrbwap/html/2024-01/28/nw.D110000renmrb_20240128_6-04.htm) · [报告转载](https://yjj.huainan.gov.cn/group4/M00/0C/E6/rB40qWXe3e-AXU2xAA8VxwPWzh0060.pdf)
- **上海胶州路（2010）**：节能改造中的电焊火花引燃保温材料，火沿外墙蔓延，58 人死亡。**翻新本身带来了隐患。** 现有来源是媒体转述，要再找官方通报。
  [HK01 报道](https://global.hk01.com/大国小事/60299281/2010年上海高楼大火58死-事后用水泥封存未拆除-原因众说纷纭)
- **Surfside（美国，2021）**：设计偏差、施工误差、后加荷载和腐蚀多年累积，最后从泳池平台开始倒塌。NIST 2026 年 6 月发布了技术结论，最终报告还没看到。
  [NIST](https://www.nist.gov/node/1918471) · [Washington Examiner](https://www.washingtonexaminer.com/policy/infrastructure/4620120/miami-surfside-condo-collapse-investigation/)
- **三丰百货（首尔，1995）**：用途变更、加层、柱距调整和屋顶空调设备等改动叠加，最终倒塌。部分细节各来源说法不一。
  [事件综述](https://en.wikipedia.org/wiki/Sampoong_Department_Store_collapse)
- **Beverly Hills Supper Club（1977）**：常被当作铝线引发火灾的例子，但起因有争议，不建议作为依据。
  [Firehouse 讨论](https://www.firehouse.com/operations-training/educational-materials/article/11299228/fire-industry-and-the-law)

### 理论框架

**Perrow《Normal Accidents》（1984）**：系统事故取决于两个维度。交互复杂性指部件之间可能发生设计时没预料到的相互作用；紧耦合指问题会很快传到别处。两者同时存在时，他认为事故从某种意义上说是「正常」的。高可靠性组织研究对这个结论有反驳，所以它不是定论。
[综述](https://encyclopedia.com/science/encyclopedias-almanacs-transcripts-and-maps/normal-accidents) · [读书笔记](https://www.jasoncollins.blog/posts/perrows-normal-accidents-living-with-high-risk-technologies) · [MIT：超越 Normal Accidents 与高可靠性](https://psas.scripts.mit.edu/home/papers/2026_Beyond_Normal_Accidents_and_High_Reliabi.pdf)

瑞士奶酪模型、故障树和 HAZOP 也是常用工具，这些我还没查证。

## 二、场景可行性

### 算得动吗

可以。住宅的尺度和现在的 FZK-Haus 接近，20 cm 网格约 3.4 万格，引擎在这台 Mac 上每步约 27 ms。手机上还没实测。

### 三张图从哪里来

这是最初的担心：至少要有三种图纸叠在同一个场景上。

1. **公开的同一栋楼。** [NIBS Common BIM Files](https://wbdg.org/node/9165) 的 Duplex 公寓，搜索结果显示有建筑、电气、暖通、给排水四套 IFC。还没确认：下载链接和许可是否可用；能否对齐；是 IFC 2x3 的旧文件；没看到燃气；是美国建筑。
2. **自己画一套典型住宅。** 住宅管线很稀疏，本质上是带类型的折线和点，比建房子简单。粗估一两天能画一版。对外要说明这是典型住宅，不是还原某一户。
3. **问群核。** 公开资料里没查到酷家乐有水电或燃气模块，这不代表没有，可以直接问有没有带水电的户型数据。

自动生成管线的研究[目前看还不成熟](https://image-ppubs.uspto.gov/dirsearch-public/print/downloadPdf/9477790)，不建议走这条路。

## 三、多维度互相影响的可行性

**规矩：每一层至少要能改变另一层，否则不放进来。** 只是叠线条，又会变成新的醋包饺子。

下表的物理依据和难度都是常识判断和估算，这轮没有查证。

| 连接 | 怎么做（低精度） | 难度 |
|---|---|---|
| 燃气 + 通风 | 现有流体解算器多跑一个标量场；天然气轻、液化气重，积聚位置不同 | 小到中 |
| 燃气 + 电路 | 浓度到爆炸范围的区域覆盖开关，一按就是火花 | 小到中 |
| 爆燃 → 窗或墙失效 → 通风改变 | 爆炸作为事件；失效复用开关门的格子机制 | 中，爆炸压力本身不模拟 |
| 火 → 线路烧坏 → 跳闸 | 按位置累计受热，到阈值触发状态变化 | 小 |
| 线路超载 → 发热 → 起火 | 简单的负载和阈值规则 | 中，可信度一般 |
| 公共烟道 → 楼层之间串烟 | 烟道作为连接空间；需要多层模型 | 中 |
| 爆炸 → 结构连续坍塌（Ronan Point） | 简化的杆件或墙板网络 | **大，只能算示意** |

**现有引擎不做的事**：燃烧化学、爆炸压力、材料热解。这些只能当作规定好的事件，不是算出来的结果。

## 四、人放在哪里

尽量不做人群涌现，恐慌太难模拟。人可以留在三个有依据的位置：

1. **人留下的痕迹（原因）**：改了线路、封了风道、多接了大功率电器。三丰百货和 Surfside 都说明，隐患常常是一次次改出来的。
2. **人的一个决定（情景）**：开门或不开、开灯或不开。这只是一个条件，不用预测他会怎么选。
3. **人承受了什么（后果）**：放一个探针，记录烟和热什么时候到。

## 五、还没解决的问题

1. **隐患的依据。** 典型图纸本身不会告诉你哪里有隐患。每个隐患都要有依据：规范、事故案例，或周老师和同事的判断。
2. **第一版放什么。** 只放哪两三个隐患，它们之间又怎样互相影响。
3. **比赛规则和群核的数据。** 这个方向可能很贴合酷家乐的家装业务，但还要向群核确认。
4. **真实感和不像游戏。** 图层有可能让它不像游戏，但这只是想法，要做出来看。
